Light-Sensing Servo Control

An Arduino reads light levels from an LDR and moves a servo to press the Dino game's jump control when the reading passes a set threshold.

↓

Project Overview_

The Arduino samples one LDR connected to analog input A0. When the reading exceeds the sketch's threshold of 22, a servo connected to pin 5 moves from 0° to 45° with a 100 ms pause at each position. This movement provides the physical jump action; the sketch also prints the sensor reading over serial.

LDR reading above 22 → Servo moves 0° → 45° → Jump action

Watch Demo on YouTube

How It Works_

  • The LDR is read from analog input A0 on each loop.
  • The sketch uses a fixed trigger threshold of 22.
  • When the reading is above 22, the servo on pin 5 moves to 0° and then 45°.
  • The servo pauses for 100 ms at each commanded position.
  • LED outputs on pins 6 and 7 are set HIGH, and sensor readings are printed over serial.

Components_

  • Arduino board
  • Light-dependent resistor (LDR)
  • Servo motor
  • LEDs
  • Jumper wires
  • Power supply
